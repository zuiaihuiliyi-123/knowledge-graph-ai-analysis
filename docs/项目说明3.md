# A10 赛题项目开发计划书 V2.0

---

## 一、项目目标

围绕 A10《基于 AIGC 的课程知识图谱智能构建与学习导航系统》，构建一套从课程资料导入、知识抽取、知识图谱构建，到智能问答与个性化学习导航的完整 Web 系统。

**核心闭环：**

> 课程资料上传 → 文档解析 → 知识点抽取 → 关系构建 → 知识融合/校验 → Neo4j 图谱存储 → 图谱可视化 → RAG 智能问答 → 基于前置关系的学习路径推荐

## 四、核心技术方案（V1.1 冻结）

### 4.1 文档解析

| 格式 | 支持 | 工具 |
|------|:----:|------|
| PDF | ✅ | pdfplumber |
| TXT | ✅ | 内置 |
| DOCX | ⬜ 预留 | python-docx |
| Markdown | ⬜ 预留 | 内置 |

**处理流程：** 上传 → 文件解析 → 文本清洗 → 章节识别 → chunk 切分 → overlap

**当前参数（V1.1 冻结，不可修改）：**

- `chunk_size`：6000 tokens
- `overlap`：400 tokens
- `extraction_concurrency`：4
- `official_temperature`：0（正式评测）/ 0.15（开发）

### 4.2 知识抽取

采用单阶段 LLM 联合抽取（冻结 V1.1）：

| 实体类型 | 关系类型（含 evidence + confidence） |
|----------|--------------------------------------|
| 概念 | PRECEDES（学习依赖，最高精度要求） |
| 定理 | CONTAINS（上下位/整体-部分） |
| 公式 | RELATED_TO（严格限制） |
| 方法 | APPLIES_TO（方法→应用对象） |

**关键原则（Prompt 强制约束）：**

- 证据不足 → 不输出
- 叙述顺序 ≠ 学习依赖
- "X 是 Y 的一种/特殊形式" → CONTAINS（严禁 PRECEDES）

**置信度说明：** `confidence` 仅表示模型自评置信度，不代表真实准确率。真实准确率只通过 Gold 数据的 Precision / Recall / F1 计算。

### 4.3 知识图谱数据模型（Neo4j）

```cypher
(:KnowledgePoint {
  kp_id: "kp_{course_id}_{uuid}",
  name: string,
  category: "概念"|"定理"|"公式"|"方法",
  description: string,
  course_id: integer,
  aliases: list,
  source_doc_ids: list,
  confidence: float,
  is_manual: boolean
})

(:KnowledgePoint)-[:PRECEDES|CONTAINS|RELATED_TO|APPLIES_TO {
  evidence: string,
  confidence: float,
  is_inferred: boolean
}]->(:KnowledgePoint)
```

### 4.4 RAG 智能问答

| 组件 | 选型 | 说明 |
|------|------|------|
| Embedding | SiliconFlow BAAI/bge-m3 | 1024 维，中文优化 |
| 向量库 | Chroma | 轻量级，本地运行 |
| 生成模型 | DeepSeek-chat | 基于检索上下文生成 |

**流程：** 用户问题 → bge-m3 向量化 → Chroma Top-K 检索 → 课程知识片段 + DeepSeek → 回答 + 引用来源

**测试结果：** 21 题，课内 20 题正确率 100%，边界拒答 1 题。

### 4.5 学习路径推荐

**算法：** 基于 PRECEDES 的图遍历（非机器学习）

**流程：** 用户标记已掌握知识点 → 查找 PRECEDES 后继节点 → 排除已掌握 → 计算优先级 → 推荐 + 可视化高亮

**降级机制（A+B 已落地）：**

- 无 PRECEDES 路径 → 回退到 CONTAINS 上层概念
- 无匹配 → 返回课程根节点

## 六、部署指南（Docker）

### 6.1 环境变量配置

创建 `backend/.env`：

```bash
# DeepSeek
LLM_API_KEY=sk-xxx
LLM_API_BASE=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

# SiliconFlow
EMBEDDING_API_KEY=sk-xxx
EMBEDDING_API_BASE=https://api.siliconflow.cn/v1
EMBEDDING_MODEL=BAAI/bge-m3

# Neo4j
NEO4J_URI=bolt://neo4j:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=your_password

# SQLite
SQLITE_DB_PATH=./data/app.db
UPLOAD_DIR=./data/uploads

# JWT
SECRET_KEY=your-secret-key-32-bytes-min
```

### 6.2 Docker Compose 完整配置

```yaml
# docker-compose.yml
version: '3.8'

services:
  neo4j:
    image: neo4j:5-community
    container_name: kg-neo4j
    ports:
      - "7474:7474"   # HTTP (Browser)
      - "7687:7687"   # Bolt (Driver)
    environment:
      - NEO4J_AUTH=neo4j/your_password
      - NEO4J_ACCEPT_LICENSE_AGREEMENT=yes
    volumes:
      - ./neo4j/data:/data
      - ./neo4j/logs:/logs
    healthcheck:
      test: ["CMD", "cypher-shell", "-u", "neo4j", "-p", "your_password", "RETURN 1"]
      interval: 10s
      timeout: 5s
      retries: 5

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: kg-backend
    ports:
      - "8000:8000"
    environment:
      - NEO4J_URI=bolt://neo4j:7687
      - NEO4J_USER=neo4j
      - NEO4J_PASSWORD=your_password
      - SQLITE_DB_PATH=./data/app.db
      - UPLOAD_DIR=./data/uploads
    volumes:
      - ./backend/data:/app/data
      - ./backend/uploads:/app/uploads
    depends_on:
      neo4j:
        condition: service_healthy
    command: uvicorn app.main:app --host 0.0.0.0 --port 8000

  frontend:
    build:
      context: ./frontend-vue
      dockerfile: Dockerfile
    container_name: kg-frontend
    ports:
      - "80:80"
    depends_on:
      - backend
```

### 6.3 Dockerfile 配置

后端 Dockerfile（`backend/Dockerfile`）：

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

前端 Dockerfile（`frontend-vue/Dockerfile`）：

```dockerfile
FROM node:18-alpine AS builder

WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80
```

### 6.4 部署命令

```bash
# 首次部署
docker-compose up -d --build

# 查看日志
docker-compose logs -f backend

# 停止
docker-compose down

# 数据持久化备份
docker-compose exec neo4j neo4j-admin backup --backup-dir=/backups
```

## 七、风险预案

| 风险 | 应对措施 |
|------|----------|
| LLM 抽取准确率低 | ① Prompt 决策树化 ② 教师手动编辑兜底 ③ Gold 标注持续验证 |
| Neo4j 资源不足 | ① 优化 Cypher 查询 ② 本地社区版备用 |
| API 调用超时/限流 | ① 异步处理 + 状态轮询 ② 文档分块 + 并发控制 |
| 时间不够 | 优先保证：全流程跑通 → 图谱可视化 → RAG 问答 → 路径推荐 |
| 评测数据污染 | V1.1 冻结 + 禁止"跑一次→改一次"的追数据循环 |
