# 数据库设计说明

> 本文档汇总系统当前的数据存储设计，来源为代码实际定义：关系型数据见 `backend/app/core/sql_database.py`，图数据见 `backend/app/core/database.py`。
>
> 系统采用**双存储**：SQLite（关系型，存用户/课程/文档/学习记录/向量）+ Neo4j（图，存知识点与关系）。

---

## 一、存储架构

| 存储 | 类型 | 存什么 | 落地文件/模块 |
|------|------|--------|---------------|
| SQLite | 关系型 | 用户、课程、文档、学习记录、知识点向量 | `backend/app/core/sql_database.py` |
| Neo4j | 图数据库 | `KnowledgePoint` 节点 + 四类关系 | `backend/app/core/database.py` |

- `course_id` 三端统一为**整数**：SQLite 自增整数 → Neo4j 存整数属性 → API 传整数。
- `t_learning_record.kp_id` 是**逻辑外键**，指向 Neo4j 的 `KnowledgePoint`，不建物理外键（跨库无法建）。
- 第一阶段用 SQLite（零部署、Python 标准库）；第二阶段迁移 MySQL 仅替换 `sql_database.py` 底层连接实现，表名、字段名、方法签名保持不变，业务代码零改动。

## 二、SQLite 关系型表（5 张）

### 2.1 t_user 用户表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | INTEGER | PK AUTOINCREMENT | 主键 |
| username | TEXT | NOT NULL UNIQUE | 登录名 |
| password_hash | TEXT | NOT NULL | 密码哈希 |
| role | TEXT | NOT NULL DEFAULT 'student'，CHECK ∈ {teacher, student} | 角色 |
| display_name | TEXT | | 显示名 |
| email | TEXT | | 邮箱 |
| is_active | INTEGER | NOT NULL DEFAULT 1，CHECK ∈ {0, 1} | 是否启用 |
| created_at | TEXT | NOT NULL DEFAULT 本地时间 | 创建时间 |
| updated_at | TEXT | NOT NULL DEFAULT 本地时间 | 更新时间 |

索引：`idx_role (role)`

### 2.2 t_course 课程表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| course_id | INTEGER | PK AUTOINCREMENT | 主键（三端统一的整数） |
| course_code | TEXT | UNIQUE | 课程编号 |
| course_name | TEXT | NOT NULL | 课程名 |
| description | TEXT | | 课程描述 |
| teacher_id | INTEGER | NOT NULL，FK → t_user(user_id) | 授课教师 |
| status | INTEGER | NOT NULL DEFAULT 1，CHECK ∈ {0, 1} | 状态 |
| created_at | TEXT | NOT NULL DEFAULT 本地时间 | 创建时间 |
| updated_at | TEXT | NOT NULL DEFAULT 本地时间 | 更新时间 |

索引：`idx_teacher_id (teacher_id)`

### 2.3 t_document 文档表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| doc_id | INTEGER | PK AUTOINCREMENT | 主键 |
| course_id | INTEGER | NOT NULL，FK → t_course(course_id) | 所属课程 |
| uploader_id | INTEGER | NOT NULL，FK → t_user(user_id) | 上传者 |
| file_name | TEXT | NOT NULL | 文件名 |
| file_type | TEXT | NOT NULL，CHECK ∈ {PDF, TXT, DOCX, MD} | 文件类型 |
| file_size | INTEGER | NOT NULL | 文件大小 |
| file_sha256 | TEXT | | 文件哈希 |
| file_path | TEXT | | 存储路径 |
| parse_status | TEXT | NOT NULL DEFAULT 'UPLOADED'，CHECK ∈ {UPLOADED, PARSING, PARSED, FAILED} | 解析状态 |
| extract_status | TEXT | NOT NULL DEFAULT 'PENDING'，CHECK ∈ {PENDING, EXTRACTING, COMPLETED, FAILED} | 抽取状态 |
| error_message | TEXT | | 错误信息 |
| chunk_count | INTEGER | NOT NULL DEFAULT 0 | 分块数 |
| entity_count | INTEGER | NOT NULL DEFAULT 0 | 抽取实体数 |
| relation_count | INTEGER | NOT NULL DEFAULT 0 | 抽取关系数 |
| vector_collection | TEXT | | 向量集合名 |
| created_at | TEXT | NOT NULL DEFAULT 本地时间 | 创建时间 |
| updated_at | TEXT | NOT NULL DEFAULT 本地时间 | 更新时间 |

索引：`idx_course_id`、`idx_uploader_id`、`idx_parse_status`、`idx_extract_status`

### 2.4 t_learning_record 学习记录表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| record_id | INTEGER | PK AUTOINCREMENT | 主键 |
| user_id | INTEGER | NOT NULL，FK → t_user(user_id) | 用户 |
| course_id | INTEGER | NOT NULL，FK → t_course(course_id) | 课程 |
| kp_id | TEXT | NOT NULL | 知识点（逻辑外键 → Neo4j KnowledgePoint） |
| status | TEXT | NOT NULL DEFAULT 'MASTERED'，CHECK ∈ {MASTERED, LEARNING, RECOMMENDED} | 掌握状态 |
| mastery_level | INTEGER | NOT NULL DEFAULT 100，CHECK BETWEEN 0 AND 100 | 掌握程度 |
| source | TEXT | NOT NULL DEFAULT 'MANUAL'，CHECK ∈ {MANUAL, SYSTEM} | 来源 |
| last_learned_at | TEXT | | 最近学习时间 |
| created_at | TEXT | NOT NULL DEFAULT 本地时间 | 创建时间 |
| updated_at | TEXT | NOT NULL DEFAULT 本地时间 | 更新时间 |

约束：`UNIQUE (user_id, course_id, kp_id)`（同一用户对同一知识点仅一条记录）
索引：`idx_user_course (user_id, course_id)`、`idx_course_kp (course_id, kp_id)`

### 2.5 t_kp_embedding 知识点向量表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| course_id | INTEGER | PK（复合主键） | 课程 |
| kp_id | TEXT | PK（复合主键） | 知识点 |
| embedding | TEXT | NOT NULL | 向量（JSON 数组文本） |
| updated_at | TEXT | NOT NULL DEFAULT 本地时间 | 更新时间 |

主键：`(course_id, kp_id)`

## 四、Neo4j 图模型

### 4.1 节点 KnowledgePoint

| 属性 | 类型 | 说明 |
|------|------|------|
| kp_id | string | 业务主键，格式 `kp_{course_id}_{uuid}` |
| name | string | 知识点名称 |
| category | string | 类别 ∈ {概念, 定理, 公式, 方法} |
| description | string | 描述 |
| course_id | integer | 所属课程 |
| aliases | list | 别名 |
| source_doc_ids | list | 来源文档 |
| confidence | float | 置信度（模型自评） |
| is_manual | boolean | 是否教师手动创建 |

### 4.2 关系类型

| Cypher 类型 | 中文标签（relation_type 属性） | 语义 |
|-------------|-------------------------------|------|
| PRECEDES | 前置知识 | 学习依赖（最高精度要求） |
| CONTAINS | 包含 | 上下位/整体-部分 |
| RELATED_TO | 相关概念 | 严格限制 |
| APPLIES_TO | 应用 | 方法→应用对象 |

关系属性：`evidence`（证据）、`confidence`（置信度）、`is_inferred`（是否推理）。

### 4.3 约束与索引

| 类型 | 名称 | 定义 |
|------|------|------|
| 唯一约束 | `kp_id_unique` | `kp.kp_id IS UNIQUE` |
| 复合索引 | `kp_course_name` | `(kp.course_id, kp.name)` |
| 复合索引 | `kp_course_category` | `(kp.course_id, kp.category)` |
| 关系索引 | `precedes_course` | `[r:PRECEDES]` 的 `r.course_id`（路径推荐过滤用） |

## 六、类型映射（MySQL 迁移参考）

SQLite 无 ENUM / UNSIGNED / ON UPDATE 语法，用等价手段保留语义：

| MySQL | SQLite |
|-------|--------|
| BIGINT / INT / TINYINT UNSIGNED | INTEGER |
| VARCHAR / CHAR / TEXT / ENUM | TEXT（ENUM 取值用 CHECK 约束保留） |
| DATETIME | TEXT（存 `YYYY-MM-DD HH:MM:SS`） |
| AUTO_INCREMENT | INTEGER PRIMARY KEY AUTOINCREMENT |
| DEFAULT CURRENT_TIMESTAMP | DEFAULT (datetime('now','localtime')) |
| ON UPDATE CURRENT_TIMESTAMP | 应用层 UPDATE 时显式写 updated_at |
