## 六、典型用例（完整问答摘录）

### 用例 10：方法用法（含代码示例生成）

> **问**：如何用 types 模块给对象动态绑定方法？
> **检索 top3**：types模块 / MethodType / 动态类型
> **答**（节选）：
> `types` 模块提供 `MethodType` 工具用于动态绑定方法……利用 Python 的**动态类型**特性在运行时为对象**动态增加成员**。
> ```python
> import types
> class MyClass: pass
> def say_hello(self): return "Hello!"
> obj = MyClass()
> obj.say_hello = types.MethodType(say_hello, obj)
> print(obj.say_hello())  # Hello!
> ```
> 绑定后的方法只对当前对象有效，不会影响类本身或其他实例。

## 七、问题分析

1. **前置知识类问题 top-3 召回不足（Q16/Q17）**：当问题问"学习 X 前要掌握什么"时，目标是 X 的**前置节点**（如 `特殊方法→运算符重载`、`继承→多态`），但向量相似度优先召回的是 X 本身及其近义节点，前置节点排名靠后（4–5 位）。由于 `ask()` 使用 top_k=5，回答仍能正确，但若降低 top_k 会漏答。
   **改进**：对含"之前/先/前置/前提"的问题，在向量召回基础上**沿 PRECEDES 边做图召回增强**（取目标节点的直接前驱），或将该类问题 top_k 动态调大。
2. **知识库信息量限制（Q19）**：位运算符仅有一条描述，无具体示例，模型能如实说明"知识库无更详细示例"。属于图谱内容颗粒度问题，可在节点 description 中补充示例字段（见待办：节点详情补示例）。

## 八、结论

- RAG 问答链路在 69 节点真实图谱上**回答正确率 100%**，检索命中率 90%+，边界问题**诚实拒答**，满足赛题交付要求。
- 真向量检索（bge-m3）较旧关键词检索的关键提升：Q2「继承」被近义「多继承」而非字面命中、Q21 课外问题不再随机匹配节点，语义相关性显著。
- 待优化项集中于**前置知识类问题的图召回增强**，属可迭代增强而非阻断性问题。
