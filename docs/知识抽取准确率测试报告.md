# 知识抽取准确率测试报告

> 交付物对应赛题「知识抽取测试报告」。本报告记录一次完整的 **初测 → 问题定位 → Prompt 修复 → 复测** 工程闭环，量化 LLM 从课程文本中自动抽取知识点实体与关系的准确率。

> **口径说明（术语约定，全文固定）**：关系自带的 `confidence`（置信度）是模型对当前抽取结果的**自评**，不代表真实准确率——严禁出现「Confidence=0.93，因此准确率为 93%」这类表述。真实准确率仅由本报告第二节的 Gold 标注 + P/R/F1 计算得出。同理，`default_relation_confidence`（0.8）仅在模型未返回 confidence 时用于缺省值填充与工程数据完整性，**不参与** Precision / Recall / F1 的准确率计算。

---

## 一、测试目的

量化系统「文档 → LLM 抽取 → 三元组」环节的抽取质量，定位系统性错误并验证修复效果，作为后续 Prompt 迭代的基线。

## 二、测试对象与方法

### 2.1 测试源文本

选用 `backend/data/sample_docs/数据结构第一章.txt`（《数据结构》第一章，共 11 行），内容覆盖「线性表及其两种存储结构」「栈与队列」两类典型的**包含关系**（"X 是 Y 的一种 / X 是 Y 的存储结构"）。选它的原因：体量小、便于人工精确标注，且包含最容易混淆的 CONTAINS / PRECEDES 边界。

### 2.2 金标准（人工标注）

| 类型 | 内容 |
|------|------|
| 实体（5） | 线性表、顺序表、链表、栈、队列 |
| 关系（4） | 线性表 CONTAINS 顺序表 / 链表 / 栈 / 队列 |

标注依据：文本中「线性表有两种存储结构：顺序存储结构和链式存储结构」「栈是一种操作受限的线性表」「队列也是一种操作受限的线性表」均为**包含关系**（上层概念包含子概念），按提取 Prompt 的规则 2 应为 `CONTAINS`。

### 2.3 匹配规则

- **实体**：名称精确匹配，并做同义归一化（`顺序存储结构`→`顺序表`，`链式存储结构`→`链表`）。
- **关系**：
  - **严格匹配**：`(source, type, target)` 三元组完全一致才计命中。
  - **宽松匹配**：只要 source–target 节点对正确即计命中（忽略关系类型与方向），用于区分"找错节点"与"找对节点但判错类型"两类错误。

### 2.4 评估指标

Precision / Recall / F1，每轮抽取结果独立计算，多轮取平均。

## 四、问题定位

### 错误类型 1（系统性）："X 是 Y 的一种"被误判为 PRECEDES

**现象**：`线性表 → 栈`、`线性表 → 队列` 在 3 轮中全部被判为 `PRECEDES`，而金标准为 `CONTAINS`。

**根因**：Prompt 中规则 1（PRECEDES）被标注为"优先级最高"，触发词含"基础/先修/前提"等。文本"栈是**一种**操作受限的线性表"中"受限"一词让模型倾向理解为"先学线性表、再学栈"的学习顺序，从而套用 PRECEDES。

**影响**：严格关系 F1 偏低（46.67%）的**主因**，且会直接污染后续学习路径推荐（PathRecommender 依赖 PRECEDES 边）。

### 错误类型 2（偶发）：同义表达拆分导致自环假阳性

**现象**：第 2 轮同时抽出 `顺序存储结构` 与 `顺序表`，并生成 `顺序存储结构 CONTAINS 顺序表`，归一化后变成自环 `顺序表 CONTAINS 顺序表`。

**根因**：文本用"顺序存储结构（顺序表）"括号别名写法，模型未统一为规范实体。

---

## 五、修复措施（`knowledge_extractor.py`）

1. **删除"优先级最高"标签并收窄 PRECEDES 定义**：从"识别到任何先后顺序关系必须用 PRECEDES"改为"只有存在明确'必须先掌握 A 才能学 B'的依赖时才用 PRECEDES"。
2. **新增关键排除规则**：`"X 是 Y 的一种 / 特殊形式 / 变体"` 一律用 `CONTAINS`（方向 Y→X），严禁 PRECEDES。
3. **新增正反例（示例5）**：
   - `"栈是一种操作受限的线性表"` → 正确 `CONTAINS`，错误 `PRECEDES`；
   - `"要学习多态，必须先掌握继承"` → 正确 `PRECEDES`。
4. **temperature 0.3 → 0.15**：关系类型判别需稳定，降低随机性。

## 七、复测残余误差分析

第 1 轮额外抽出了 2 条 `RELATED_TO` 关系：`顺序表 ↔ 链表`、`栈 ↔ 队列`。这两条**类型判断正确**（确为"相关概念"），且语义上成立（同属线性表的两种存储结构 / 同为受限线性表），但不在本报告的最小金标准内（金标准只列了 4 条明确的"是一种/存储结构"包含关系）。

**结论**：该残余属**金标准粒度选择**（是否纳入"相关概念"边）而非关系类型误判，非模型缺陷。若要进一步收敛，可在金标准中显式补充"相关概念"边，或在抽取约束中限定"仅抽取包含/前置关系"。

---

## 八、结论

1. **实体抽取始终 100% 准确**（F1=1.0）。
2. **关系抽取经一次 Prompt 修复，严格 F1 从 0.4667 提升至 0.9333（+100%），召回率从 0.5 提升至 1.0**，已超过赛题 70% 的准确率目标。
3. 修复成本极低（仅改 Prompt 规则 + 2 个 Few-shot + 温度），收益极高，验证了"Prompt 工程是提升抽取质量的第一杠杆"。
