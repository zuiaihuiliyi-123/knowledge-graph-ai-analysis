## 开发计划（按优先级）

### 第一阶段：核心功能验证（第 1-2 周）

- [x] 项目结构搭建
- [x] 配置 DeepSeek API Key，测试 LLM 知识提取，成功从测试文本中抽取 JSON 格式三元组
- [x] 搭建 Neo4j AuraDB（免费云数据库），本地 Python 脚本测试连接与 Cypher 查询

- [x] 跑通 **"上传文档 → 文本解析 → LLM 抽取三元组 → 存储到 Neo4j"** 端到端流程

### 第二阶段：可视化与交互（第 3-4 周）

- [X] 后端开发图谱查询 API（`/api/v1/graph/{course_id}`），返回节点与关系数据

- [X] 实现图谱交互（缩放、拖拽、点击节点显示知识点详情）
- [x] 完善教师端功能（文档上传、图谱预览、手动增删改节点/关系）
- [x] 完善学生端功能（图谱浏览、知识点搜索、详情查看）

### 第三阶段：智能功能（第 5-6 周）

- [x] 构建向量检索库：课程文档分块 → Embedding → 存入 Chroma 向量库

- [x] 实现学习路径推荐：用户标记已掌握知识点 → 基于图谱前置关系 → 推荐下一步学习列表
- [ ] 测试准确率：知识抽取准确率测试 + 智能问答测试集（20+ 问题）评估，撰写测试报告

### 第四阶段：完善与交付（第 7-8 周）

- [ ] 企业要求材料：使用说明文档、Prompt 工程记录、知识抽取测试报告、问答测试集与结果、图谱构建示例

## 风险预案

| 风险 | 应对措施 |
|------|----------|
| **LLM 抽取准确率低** | ① 教师端提供手动编辑功能 ② 优化 Prompt（Few-shot） ③ 准确率目标不低于 70% |
| **Neo4j 免费版资源不足** | ① 优化 Cypher 查询 ② 本地部署社区版备用 |
| **API 调用超时/限流** | ① 异步处理 + 状态轮询 ② 文档分块，控制单次输入长度 |
| **时间不够** | 优先保证全流程跑通、图谱可视化、RAG 问答；路径推荐可简化实现 |
