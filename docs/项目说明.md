# 项目说明文档

## 开发计划（按优先级）

### 第一阶段：核心功能验证（第1-2周）
1. ✅ 项目结构搭建
2. ⬜ 配置 DeepSeek API Key，测试 LLM 知识提取
3. ⬜ 搭建 Neo4j AuraDB（免费云数据库）
4. ⬜ 实现文档解析（至少支持 PDF 和 TXT）
5. ⬜ 跑通"上传文档 → 提取知识 → 存储到Neo4j"完整流程

### 第二阶段：可视化与交互（第3-4周）
6. ⬜ 前端集成 ECharts，展示知识图谱
7. ⬜ 实现图谱交互（缩放、拖拽、节点点击）
8. ⬜ 完善教师端功能（上传、预览、编辑）
9. ⬜ 完善学生端功能（浏览、搜索）

### 第三阶段：智能功能（第5-6周）
10. ⬜ 实现智能问答（RAG）
11. ⬜ 实现学习路径推荐
12. ⬜ 测试准确率，撰写测试报告

### 第四阶段：完善与交付（第7-8周）
13. ⬜ 项目文档编写
14. ⬜ 录制演示视频
15. ⬜ PPT制作
16. ⬜ 最终测试与Bug修复

## 技术准备清单

- [ ] 注册 DeepSeek API Key（https://platform.deepseek.com）
- [ ] 创建 Neo4j AuraDB 免费实例（https://neo4j.com/cloud/aura/）
- [ ] 准备一份测试用的课程文档（如《数据结构》第一章）
- [ ] 安装项目依赖 `pip install -r backend/requirements.txt`
